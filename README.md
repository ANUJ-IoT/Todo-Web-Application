# Todo App

A Todo web application built using React.js, Node.js, Express.js, and MySQL. It allows users to manage their daily tasks with authentication and track their productivity through a donut chart.

## Features

- **User Authentication:** Registration and login functionality.
- **Task Management:** Create, update, delete, and manage todo lists.
- **Productivity Tracking:** A donut chart displaying:
  - Total tasks created
  - Completed tasks
  - Pending tasks
  - Failed tasks (tasks that exceed their deadlines)
- **Task Status:** Tracks tasks based on their completion status and deadlines.
- **User-specific Data:** Each user can manage and track their own tasks.

## Tech Stack

- **Frontend:** React.js
- **Backend:** Node.js, Express.js
- **Database:** MySQL
- **Authentication:** User authentication
- **Charts:** Donut Chart

## Overview

The application provides a simple interface for managing daily tasks and monitoring productivity. The dashboard offers a visual representation of task progress, helping users keep track of completed, pending, and failed tasks.
